## 📌 Projetos em destaque

### 🎬 API de Bilheteria de Cinema
API RESTful desenvolvida com **Java**, **Spring Boot** e **PostgreSQL**, voltada para gerenciamento de filmes, sessões e ingressos.

**Principais pontos:**
- Estrutura em camadas com controllers, services e repositories
- Persistência de dados com PostgreSQL
- Aplicação de conceitos de Programação Orientada a Objetos
- Desenvolvimento focado em backend e organização de responsabilidades

🔗 Repositório: [api-bilheteria-de-cinema](https://github.com/Rafpazzz/api-bilheteria-de-cinema)

---

### ⚡ Pokédex Explorer
Aplicação CLI desenvolvida em **Java 21** para consumir a PokéAPI, consultar Pokémon, listar resultados, filtrar por tipo e comparar status.

**Principais pontos:**
- Consumo de API externa com HttpClient
- Conversão de JSON com Jackson
- Uso de DTOs, services e client HTTP
- Organização de código sem depender de frameworks
- Tratamento de erros e testes básicos

🔗 Repositório: [Pokedex_Explorer](https://github.com/Rafpazzz/Pokedex_Explorer)

---

### 🚗 Locadora de Carros Web
Aplicação web para gerenciamento de locação de veículos, desenvolvida com **Ruby on Rails**, **MySQL**, **Devise** e **Bootstrap**.

**Principais pontos:**
- Autenticação de usuários com Devise
- Separação de permissões entre administrador e usuário comum
- Paginação com Kaminari
- Interface web com Bootstrap

🔗 Repositório: [Site_Locadora_Carros](https://github.com/Rafpazzz/Site_Locadora_Carros)
