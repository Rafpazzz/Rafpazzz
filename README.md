## 📌 Projetos em destaque

### 🎬 MovieHub API
API REST em **Java 21** e **Spring Boot** para catálogo de filmes, watchlist, favoritos e recomendações, com consumo da API da TMDB.

**Principais pontos:**
- Estrutura em camadas (controller, service, repository, mapper e DTOs)
- Persistência em PostgreSQL com migrations via Flyway
- Cache das respostas da API externa para agilizar consultas
- Ambiente conteinerizado com Docker e Docker Compose

🔗 Repositório: [MovieHub_API](https://github.com/Rafpazzz/MovieHub_API)

---

### ⚡ Pokédex Explorer
Aplicação CLI em **Java 21** para consumir a PokéAPI, consultar Pokémon, listar resultados, filtrar por tipo e comparar status.

**Principais pontos:**
- Consumo de API externa com HttpClient e conversão de JSON com Jackson
- Uso de DTOs, services e client HTTP, sem depender de frameworks
- Tratamento de erros e testes básicos

🔗 Repositório: [Pokedex_Explorer](https://github.com/Rafpazzz/Pokedex_Explorer)
